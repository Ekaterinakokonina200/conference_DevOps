# Открытые SSH-ключи (ЛР №7)

Ansible разрешает вход на узлы только по этим ключам (`exclusive`: другие
ключи удаляются). Здесь лежат только ОТКРЫТЫЕ ключи (`*.pub`); закрытые ключи
в репозиторий не добавляются (это проверяет `make infra-check`).

| Файл | Чей ключ |
|---|---|

| `mariya.pub` | Баранова М. Г. |
| `amylanga.pub` | Отхонова А. А. |
| `ansible.pub` | пользователь `infra` на управляющем узле conference-app |
